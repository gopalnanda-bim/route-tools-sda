# route-tools-sda

pyRevit tools for routing and numbering electrical devices in Revit

## Who is this for?

This extension is designed for:
- Electrical planners (Elektroplaner)
- BIM modellers working in TGA
- Fire alarm (BMA), emergency lighting (Sicherheitsbeleuchtung), and PA/SAA projects

It is **not** intended for architects or general Revit users.

## How it works (short)

### Draw Route
1. Run the tool in a 2D plan view
2. Click devices in the desired order
3. The tool draws route lines and numbers devices automatically

### Reorder Route
1. Select existing route detail lines (TAB to select the chain)
2. Run the tool
3. Choose which parameter to renumber
4. Optionally reverse direction or set a loop value
