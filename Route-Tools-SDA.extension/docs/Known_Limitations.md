Known limitations (v1.0.0)

Works only in 2D views (Plan / RCP / Drafting)

Requires writable instance fields (String/Integer). No automatic field creation.

Uses Detail Lines (view-specific), not model lines

Reorder depends on connected route lines (gaps reduce detection)

Matching uses SNAP distance; large offsets can reduce accuracy

This is “professional software behavior”: you tell users what’s guaranteed.
